# 工作台 Android App

个人工作台网站的原生安卓壳（WebView）+ 各板块桌面/锁屏小组件。

## 安装
1. 手机浏览器（或电脑）下载 `workbench-app.apk`
2. 点击安装（小米手机需允许"安装未知应用"：设置→应用设置→授权管理→应用内安装）
3. 打开 App，首次进入需联网加载网站内容

## 使用
- **App**：打开即进入工作台网页，数据存在 App 内（可先到网页"管理→导出数据"，再到 App"管理→导入数据"迁移）
- **桌面小组件**：长按桌面→添加小部件→找到"工作台"→选你要的板块组件（工作任务/生活事务/学习/书架/临时备忘等 9 个）
- **锁屏组件**：小米 15 锁屏界面→长按/编辑→添加小组件→选工作台板块
- 组件点击→直接打开 App 对应板块；App 内改动数据→组件自动刷新

## 说明
- 小组件显示的数据来自 App 内的操作（WebView 桥接镜像），网页浏览器里的数据需用"导出/导入"迁入 App
- 首次构建版本 1.0
